# sha_copy 사용 가이드

리액트(JSX) 몰라도 되는, 순수 HTML + CSS + 자바스크립트로 만든 실제 사이트
미리보기예요. 여기서 디자인/화면 구성 작업을 하시면 됩니다.

## ⚠️ index.html을 더블클릭해서 열면 절대 안 됩니다

파일 탐색기에서 `index.html`을 더블클릭해서 열면 (`file://...` 주소로 뜨면)
CSS도 다 깨지고 화면도 텅 비어 보여요. 브라우저가 보안상 `file://`에서는
데이터를 가져오는 코드 자체를 막아버리기 때문입니다. 아래 순서대로
**반드시 로컬 서버를 통해서** 열어야 합니다.

---

## 1. 처음 한 번만 하면 되는 것

### 1-1. 프로젝트 받기

이미 폴더를 받으셨다면 이 단계는 건너뛰고 최신 내용만 받아오면 됩니다:

```bash
git pull
```

처음 받는 거라면:

```bash
git clone https://github.com/KHolyh2o/Graduation-Exhibition.git
cd Graduation-Exhibition
```

### 1-2. 필요한 프로그램 설치 (딱 한 번)

프로젝트 폴더 맨 위(루트)에서:

```bash
npm install
```

시간이 좀 걸릴 수 있어요. 한 번만 하면 그다음부턴 안 해도 됩니다.

---

## 2. 실행하는 법 (작업할 때마다)

프로젝트 폴더 맨 위(루트)에서:

```bash
npm run sha_copy
```

터미널에 이런 식으로 주소가 뜹니다:

```
INFO  Accepting connections at http://localhost:3000
```

**이 주소를 그대로 열면 안 되고, 끝에 `sha_copy/`를 붙여서 열어야 합니다.**
포트 번호(3000 부분)는 매번 다를 수 있으니 항상 터미널에 실제로 뜬 번호를
보고 그 뒤에 `sha_copy/`만 붙이세요.

예: 터미널에 `http://localhost:3000`이 떴다면 →
브라우저에 `http://localhost:3000/sha_copy/` 입력해서 접속

파일을 저장하고 브라우저에서 새로고침하면 바로 반영됩니다.

---

## 3. 어디를 고치면 되나요

| 페이지     | html 파일         | js 파일               |
|-----------|-------------------|------------------------|
| 메인       | `index.html`      | `js/index.js`          |
| 작품소개   | `project.html`    | `js/project.js`        |
| 학부소개   | `department.html` | `js/department.js`     |
| 기록들     | `gallery.html`    | `js/gallery.js`        |
| 과거전시보기| `others.html`    | `js/others.js`         |
| 404        | `404.html`        | `js/others.js` (공용)  |

```
sha_copy/
├── index.html, project.html, department.html, gallery.html, others.html, 404.html
├── css/    ← 디자인(색, 폰트, 간격 등)은 여기
├── js/     ← 버튼 클릭, 캐러셀, 모달 같은 동작은 여기
└── images  ← 이미지 파일은 여기에 넣기
```

- **디자인 고치고 싶으면** → `css/` 안의 해당 페이지 css 파일
- **화면 구성(문구, 섹션 순서 등) 고치고 싶으면** → 해당 `.html` 파일
- **동작(버튼 누르면 뭐가 뜨는지 등) 고치고 싶으면** → 해당 `js/*.js` 파일
- **새 페이지 만들고 싶으면** → `.html` 파일 하나 + 필요하면 `js/*.js` 파일 하나 추가

## 4. 진짜 프로젝트랑 연결되어 있는 것 2가지

이것만 알아두시면 됩니다 — 이 두 가지는 **사본이 아니라 진짜 파일**이에요:

1. **데이터** — 각 `js/*.js` 파일 맨 위 `import { ... } from '../../src/data/...js'`
   줄이 학생 이름·작품 정보 같은 데이터를 진짜 프로젝트에서 그대로 가져옵니다.
   **이 줄은 지우지 마세요.**
2. **이미지** — `sha_copy/images` 폴더는 진짜 `public/images` 폴더로 가는
   바로가기예요. 여기에 사진을 넣으면 진짜 프로젝트에도 바로 들어갑니다.
   **폴더 이름을 바꾸거나 지우지 마세요.**

나머지(HTML 구조, CSS, JS 동작)는 전부 sha_copy 안에서만 쓰이는 독립적인
파일이에요. 여기서 디자인을 다 잡고 나면, 나중에 실제 리액트 코드로
옮겨 담는 작업은 따로 진행합니다 (그건 제가 확인하면서 같이 합니다).

## 5. 작업 다 끝나면 — git으로 올리기

파일 저장하고 브라우저에서 확인 끝났으면, 아래 순서대로 올려주세요.
(터미널에서 프로젝트 폴더 위치에 있는 상태로 입력)

```bash
git add sha_copy
git commit -m "작업 내용 한 줄 설명"
git push
```

한 줄씩 설명하면:
- `git add sha_copy` → sha_copy 폴더에서 바꾼 내용을 "올릴 목록"에 담기
- `git commit -m "..."` → 담은 내용을 "이번 작업 묶음"으로 저장 (따옴표 안에
  뭘 했는지 짧게 적으면 됨, 예: `"메인페이지 색상 수정"`)
- `git push` → 그 묶음을 GitHub에 실제로 올리기

이미지 파일을 `sha_copy/images`에 새로 넣었다면, 그건 진짜 `public/images`에
들어간 거라서 `git add sha_copy` 대신 `git add .`로 전체를 담아야 같이
올라갑니다.

---

## 6. 자주 하는 실수

- `index.html`을 더블클릭해서 열었다 → 반드시 `npm run sha_copy`로 서버
  켜고, 뜨는 주소 뒤에 `/sha_copy/`를 붙여서 접속하세요.
- `js/*.js` 맨 위 `import` 줄을 지웠다 → 데이터가 하나도 안 뜹니다. 되돌려
  주세요.
- `images` 폴더 이름을 바꾸거나 지웠다 → 이미지가 전부 깨집니다.
- 작업하기 전에 `git pull`을 안 했다 → 다른 사람이 먼저 올린 내용과
  충돌날 수 있어요. 작업 시작 전에 항상 `git pull` 먼저 해주세요.

막히면 편하게 물어보세요.
